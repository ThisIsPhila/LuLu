# Readable local private export

Implemented locally on 26 October 2026. Previous goal work progressed implementation/verification; whole-product completion remains unproven and the goal is active.

The existing private record detail now hosts readable export without a new destination/sidebar/CSS. Preparing makes an in-memory copy only. A separate user Download action follows explicit scope: unencrypted copy, original/all saved text revisions, no unsaved draft edits, not an encrypted recovery backup, and Quick exit cannot conceal a file already downloaded. Media exports original bytes as one generic MIME-derived filename; app metadata is explicitly excluded.

The service validates every text revision through the existing parser, retains source IDs/provenance/content/digests and flags exportedAt as device time. Existing vault chain/integrity validation is reused. Media are returned byte-for-byte after authenticated vault read. Both vaults expose only an additional assertion of existing live owner/generation authority; export never creates authority. Reads recheck that authority after awaits; a closure rechecks just before download. Cancel/exit invalidate callbacks, discard prepared references and revoke object URLs. Download is requested only by explicit click; status does not assert that an OS file write succeeded.

Verification:98 focused export/device-key/media/offline/ordinary/private tests pass with standard Node command; hosted main-only build and Firebase guard pass. Five new export tests cover full original/revision content, exact media, unchanged stored originals, identity/lock/late-result rejection and no service transport. A concurrent native key adapter's extensionless runtime import broke the normal Node command; one .ts import suffix restored standard verification without altering native key semantics or other native work.

Actual-component synthetic browser verification produced readable JSON and image downloads; parsed JSON retained original data, and image bytes/hash matched exactly. Prepare/cancel/exit states were observed. The first interrupted download observation was rerun with HMR disabled to isolate concurrent native packaging. Raw output, source hashes, confirmation screenshot and downloaded synthetic artifacts are in .sdd/evidence/private-export/.

This supports local text/media records only. Legacy cloud record export, ordinary export, encrypted backup, key recovery, restore/cross-device transfer, deletion and full offline authorization remain open. No deployment, push, commit, cloud mutation or paid transport. Owner-authenticated native/phone download acceptance and final design acceptance are pending. Existing concurrently added native platform/key-storage work was preserved; this assessment is not native security acceptance.
