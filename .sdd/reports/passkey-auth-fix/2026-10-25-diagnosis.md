Google Cloud request logs show HTTP500 at register/verify and login/verify. The deployed handler suppresses the underlying exception; no corresponding stderr diagnostics were available.

MCP did not expose runtime identity/IAM policy detail; parent used existing Firebase connection with read-only Google API calls, without printing tokens.
