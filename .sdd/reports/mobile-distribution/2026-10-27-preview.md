## Release

The owner requested GitHub mobile packages, repository description and installation instructions. Published private GitHub prerelease `android-ios-preview-2026-10-27` with an Android debug APK, a registered-device iPhone app archive, and `SHA256SUMS.txt`. GitHub main README was updated in commit `e09f5caeda54c6c6c3038cb10b72a67bd3c29e16`; the repository description was set to “LuLu is a journal and storybook for everyday writing and protected personal documentation.” The repository was private at the time of that release.

The owner subsequently made the repository public and chose to keep the registered-iPhone package private. Its GitHub release asset was removed and its verified local copy retained in `dist/mobile/LuLu-iOS-registered-device.zip`. The old public asset URL returned HTTP 404 after removal; the Android link returned HTTP 302. Release notes and checksum now reference Android only, and the public README was updated in commit `b28897c135180d362d909954cf3585cafc394937`. The iPhone archive may have been publicly accessible between the visibility change and removal; access during that interval was not established.

## Limits

Android debug signing is for testing. A generally accessible iOS beta needs an Apple distribution/TestFlight setup; do not present the registered-device archive as such.
