# Lu cloud chat demo: local implementation

The owner approved a temporary cloud privacy-processing step receiving original text before Lu, with on-device privacy processing remaining the long-term direction. The app must disclose the cloud processing and require a user to review the scrubbed output before sending it to Lu. Detection can miss identifiers; do not claim complete anonymization.

`/lu/scrub` and `/lu/chat` are separate backend stages using the existing server-only key. A short-lived, single-use, account-bound hash ticket ties the reviewed text to the scrub output; no original or transformed message is saved in the ticket. Abandoned tickets have an expiration timestamp, but automatic deletion is not configured. Provider `store:false` is requested; do not infer provider data retention guarantees. Chat has English, Afrikaans and isiZulu selection; language quality is unverified. These stages have not been deployed or tested with a live model.

GPT Live, enforced active voice time and email notifications remain separate unfinished work. The owner-only in-app account activity queries Firebase Auth and does not send email.
