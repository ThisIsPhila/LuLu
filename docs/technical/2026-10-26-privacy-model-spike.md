# Privacy model spike: result and integration handoff

The isolated browser proof succeeds. GLiNER Small v2.1 INT8, standalone Tokenizers.js and ONNX Runtime Web run through the Capacitor plugin's web adapter and LuLu's shared PrivacyProcessor. Source/reproduction: [scripts/privacy-spike](../../scripts/privacy-spike/README.md). Full assessment: [compatibility report](../../.sdd/reports/privacy-model/2026-10-26-compatibility.md); raw synthetic evidence: [privacy-model](../../.sdd/evidence/privacy-model/).

The published plugin 3.3.0 fails Swift dependency resolution against LuLu's Capacitor 8.5.3: it constrains native Capacitor to 7.x. No mobile dependency is selected and no actual native model run is claimed. Keep this distinction in submission materials. Tested model + tokenizer/configuration download is about 192 MB; a working sub-100 MB package was not found in this candidate's published exports.

Shared code is in `src/services/privacy/`: processor and detector lifecycle, original-input UTF-16 entities, validated span substitution, optional existing phrase-based distancing, explicit mode selection, and checksum-verifying model installation. A public web demo is now wired at `/privacy-demo`, with account-menu Settings, browser-IndexedDB storage, installed state/removal, session prepare/unload, and an editable input, highlighted detection spans and replacement preview. A shared ONNX session stays warm across Settings/demo navigation once prepared. The explicit Run button is still required to process text. The new app detector uses ONNX Runtime Web directly; it does not load the Capacitor plugin that failed Swift resolution. Email/phone pattern checks are labeled separately from model detections. The demo does not save or transmit user text.

The local browser store is per website origin. The browser controls its storage location and quota; a universal picker for an arbitrary folder is not available. The model bundle is about 192 MB and downloads from the pinned Hugging Face revision after the user chooses the Settings action. The runtime/WebAssembly files are deployed with the web app bundle and loaded when the demo route is opened. The official hosted domain has not been updated.

For local review only, Vite preview exposes four allowlisted artifacts from `/tmp/lulu-privacy-spike` at a loopback-only route. Settings can copy that existing cache into the active preview browser's IndexedDB, avoiding a second internet transfer; sizes and SHA-256 are checked again. This development-only route is not part of Firebase Hosting.

`npm run build:app` and main-only package verification pass. Local built preview: `http://127.0.0.1:5187/privacy-demo`. The new direct-browser installer and inference path has not yet completed a full browser end-to-end run; the successful measured browser inference remains the earlier isolated harness. Do not state that the current app route has completed inference until that check is performed.
