# LuLu design references

Received 24 October 2026. Story/journal is the selected product direction; mobile-first web is the immediate delivery surface.

## Latest direction: warm, tactile character

The six [new resources](resources/2026-10-24-warm-tactile/) supersede the earlier flat-white/neutral treatment where they differ. The owner explicitly rejects flat white backgrounds. Follow warm ivory/paper, sand and stone, restrained sage accents, soft material depth, organic imagery, editorial typography and warm charcoal dark surfaces. The images show the direction for app surfaces as well as brand atmosphere; the staged phone and surrounding room are reference presentation, not a frame to impose on the web app.

## Earlier exploration

The four boards in references/ are explorations, not approved specifications. Neutral monochrome, editorial typography, tactile restraint and inclusive multilingual use guide further design. Logo Direction 02 is preferred for refinement; Direction 04 is secondary. Optional pearl/soft themes are exploratory. Typefaces, tokens, copy and interface details pictured on a board are not automatically selected. In particular, security claims pictured in mockups are not implementation evidence.

The selected Lovable/v0 frontend, once supplied and reviewed, will provide the concrete integration reference. No frontend is imported yet.
