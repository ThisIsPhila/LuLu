# LuLu UI aesthetic mockups

Three mobile screen studies following the current brand kit and warm tactile direction. They present one visual journey: Home → Writing → Reading.

- [Overview sheet](00-overview.png)
- [Home](01-home.png) · [SVG source](01-home.svg)
- [Writing](02-writing.png) · [SVG source](02-writing.svg)
- [Reading](03-reading.png) · [SVG source](03-reading.svg)

The screens use the custom LuLu wordmark, brand palette, approved journal imagery, and current journal vocabulary. They are static aesthetic studies for owner review; they do not define new behavior or change the app UI. PNGs are exported at 860 × 1864 px from 430 × 932 px vector artboards.
