# LuLu background media resources

All twelve user-supplied backgrounds are saved for visual review in the HTML media library at `docs/hackathon/review.html#media-brand`.

- `source/` retains the original PNGs.
- `web/` contains optimized WebP previews, including transparency on the coffee stains.
- Each of the six designs has a portrait and landscape variant.

These are media resources for review. They are not applied to the application UI or included in its public assets.
